# Olympus Engineering Pvt. Ltd. (OEPL) Website

A high-performance, fully responsive corporate website built for **Olympus Engineering Pvt. Ltd.** using modern web technologies.

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** JavaScript / React

## ✨ Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop screens.
- **Dynamic Layouts:** Custom components for Home, About, Services, Products, Alliances, and Contact pages.
- **Interactive Elements:** Clean navigation, responsive forms, embedded Google Maps, and custom hero sections.
